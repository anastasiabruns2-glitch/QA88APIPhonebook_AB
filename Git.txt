Копируете ссылку на проект с Git.
В pycharm : new -->  выбираем Project from version Control
         в поле URL вставляем ссылку и в следующем поле указываем папку, в которой хранятся ваши проекты
Жмем clone

Появляется сообщение с вопросом про Trust, нажимаем кнопку Trust Project
Проект склонирован, теперь его необходимо отвязать от чужого Git

В терминале Pycharm вводите команду git remote remove origin

Теперь проект отвязан!
Чтобы привязать к своему Git, заходим на вкладку Git в Pycharm и делаем Share Project on GitHub

Удачи!
